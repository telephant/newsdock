2 Primary sequence: one ingest cycle

sequenceDiagram
  participant I as C-1 Ingester
  participant G as GDELT
  participant K as C-2 Kafka
  participant F as C-3 Processor
  participant S as C-4 Sink
  participant P as C-5 Postgres
  I->>G: GET lastupdate.txt
  I->>G: GET gkg.csv.zip
  alt 404 or empty
    I->>P: slot stays pending, attempts+1
  else ok
    I->>K: gkg.raw per row
    I->>P: slot published
    K->>F: consume raw
    F->>K: gkg.clean (valid) or gkg.dlq (bad)
    K->>S: consume clean
    S->>P: INSERT ON CONFLICT DO NOTHING
    S->>K: commit offset
  end
Check
  • If the processor re-reads a message, what stops duplicates in Postgres?
  • If the ingester dies after publishing half a slot, what happens on the next cycle?
  • Where does an empty-title row end up, and who can see why?

3 Agent run

sequenceDiagram
  participant A as C-7 Agent
  participant M as C-6 MCP
  participant P as C-5 Postgres
  participant O as C-9 Ollama
  A->>M: list_new_articles(cursor)
  M->>P: seq greater than cursor
  M-->>A: articles, next_cursor
  loop each article
    A->>O: score (JSON schema output)
    A->>M: submit_analysis(id, name, payload)
    M->>P: upsert analysis
  end
  A->>A: save next_cursor
Check
  • Where does the agent persist its cursor, and what if it crashes mid-loop (is re-scoring harmless)?
  • Should the agent save the cursor only after all submissions succeed?
  • What does a first run with no cursor return (design-detail: last 24 h)?

Check

  • Retention uses ingested_at: is that the clock you want?

5 Article lifecycle

stateDiagram-v2
  [*] --> Raw: published to gkg.raw
  Raw --> DeadLetter: invalid row
  Raw --> Clean: valid row
  Clean --> Stored: upsert Postgres
  Clean --> Dropped: URL already stored
  Dropped --> [*]
  Stored --> Analysed: submit_analysis
  Stored --> Expired: older than 7 days
  Analysed --> Expired: older than 7 days
  Expired --> [*]
  DeadLetter --> [*]
Check
  • Once an article expires, may it re-enter if GDELT lists the URL again later?
  • Are dead-letter messages ever replayed, or only inspected?
