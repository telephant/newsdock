  • Is a model failure confined to one line (AC-10)?
  • Is the platform asked for tone only through include, with no other new call?

3 Data shapes

classDiagram
  class Article {
    article_id, title, url, domain
    published_at, themes, source_count
    tone_neg (optional)
  }
  class StoryGroup {
    seed: Article
    members: Article[]
    sources = sum source_count
    tone_neg = max over members
    score
  }
  class Selection {
    top: StoryGroup[]
    sections: label to StoryGroup[]
    ranking: coverage or coverage and tone
  }
  Article "1..*" --> "1" StoryGroup : grouped by StoryGrouper
  StoryGroup "*" --> "1" Selection : chosen by score, caps, labels
Check:
  • Does a group's sources add the members' counts without counting any article twice?
  • Is tone_neg optional all the way (AC-2)?
  • Does a group appear in exactly one place of the file (AC-6)?
