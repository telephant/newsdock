For T-08: a `FailureKind.robots_unreachable` result means wait `robots_failure_minutes` without counting an attempt (the row stays `pending`); every failure and success carries `crawl_delay`, which the loop passes to `HostScheduler.delay_for` and `finish`; `Fetched.body` is raw bytes with `charset` from the response (the loop decodes, falling back to UTF-8 with replacement); `FetchFailure.retry_after_seconds` feeds `after_transient_failure`.
