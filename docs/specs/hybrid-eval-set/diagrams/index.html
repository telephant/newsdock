2. Build and run

sequenceDiagram
  participant B as Builder
  participant F as Frozen files
  participant H as Harness
  B->>F: read corpus and queries
  B->>B: names from seed titles, entity queries
  B->>B: grade members by word overlap, low-overlap queries
  B->>F: write hard queries file
  H->>H: load events-hard, embed corpus per prefix
  H->>H: run 4 methods, drop seed and ignored ids
  H-->>H: tables by kind, noise, sweep, clear wins
Check
  • Why are ignored members removed instead of counted as wrong?
  • Is the output identical on a second build?
  • Where would a bad name (a verb) be caught?
