1 Component delta

flowchart LR
  V["visitor"] -->|"POST /api/auth/signup"| R["C-31 sign-up route"]
  R --> L["C-30 SignupLimiter"]
  R --> H["argon2 hash + insert"]
  U["signed-in user"] -->|"POST /api/admin/agents"| A["admin route"]
  A --> Q["C-32 quota check"]
  Q --> RP[("agents repo: count_owned")]
  S["C-33 settings"] --> L
  S --> Q
  W["C-34 web messages"] -.->|"429 / 409 text"| V
  W -.-> U
Check:
  • Does every number (limits, window, quota) come from C-33, none from code?
  • Does the limiter run before the hash, so a refused request costs no CPU?
  • Is the quota applied only when the caller's scope is "own" (owner role and token exempt)?
  • Is the limiter free of I/O and of any import of the repo (pure domain)?

2 One sign-up attempt

sequenceDiagram
  participant B as Browser
  participant A as API (C-31)
  participant L as SignupLimiter (C-30)
  participant D as Postgres
  B->>A: POST /api/auth/signup
  A->>A: sign-up open? (else 403)
  A->>A: validate email and password (else 422)
  A->>L: attempt(peer address)
  alt address or global window full
    L-->>A: refused, wait N s (nothing recorded)
    A-->>B: 429 too_many_signups, Retry-After N
  else allowed
    L-->>A: allowed (counted in both windows)
    A->>D: hash, insert user
    A-->>B: 201 (or 409 email_taken, still counted)
  end
Check:
  • Do 403 and 422 leave the limiter untouched?
  • Does a refusal by the global window leave this address's own count unchanged?
  • Is a 409 duplicate counted (it already paid for a hash)?

3 Life of one window

stateDiagram-v2
  [*] --> Empty
  Empty --> Counting: first counted attempt
  Counting --> Counting: attempt, count below max
  Counting --> Blocked: count reaches max
  Blocked --> Blocked: attempt refused, not counted
  Counting --> Empty: window time ends
  Blocked --> Empty: window time ends
Check:
  • Is the window never extended by refused attempts (an attacker cannot keep themselves blocked)?
  • Do both the per-address and the global window follow this same cycle?
  • Does max = 0 skip the whole cycle (limit off)?
