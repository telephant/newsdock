2 Create, list and act on one agent

sequenceDiagram
  participant B as Browser (user B)
  participant A as API (C-23)
  participant D as Postgres
  B->>A: POST /api/admin/agents {name}
  A->>D: INSERT agent (owner_id = B)
  A-->>B: 201 key shown once
  B->>A: GET /api/admin/agents
  A->>D: SELECT ... WHERE owner_id = B
  A-->>B: B's agents only
  B->>A: POST /api/admin/agents/{a1}/disable (a1 owned by A)
  A->>D: UPDATE ... WHERE id = a1 AND owner_id = B
  D-->>A: 0 rows
  A-->>B: 404 not_found
Check:
  • Is "not yours" indistinguishable from "does not exist" for B?
  • Is the ownership test inside the same statement as the write (no check-then-act gap)?
  • Would the owner role's request omit the owner_id predicate and succeed?
