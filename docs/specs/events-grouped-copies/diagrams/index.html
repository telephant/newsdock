2. Both arrival orders

sequenceDiagram
  participant K as Kafka
  participant S as Sink
  participant DB as Postgres
  Note over K,DB: A: mention after grouping
  K->>S: mention (event 7, copy URL)
  S->>DB: upsert mention (derived=false)
  S->>DB: link: copy is in article_sources, add (7, canonical, derived=true)
  Note over K,DB: B: mention before grouping
  K->>S: mention (event 8, URL X)
  S->>DB: upsert mention, no link yet
  K->>S: article X arrives as copy of canonical C
  S->>DB: insert_source(X to C), then link (also on a redelivery)
  S->>DB: link: stored mentions of X get (8, C, derived=true)
Check
  • Does every arrival order end with the derived row?
  • What if the link statement runs twice? (DO NOTHING)
  • What if the canonical's own mention comes later? (flag flips to real)
