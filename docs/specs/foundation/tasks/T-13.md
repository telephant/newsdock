# T-13 CI workflow
Implements: AC-12, AC-13     Components: C-9
Depends on: T-04, T-07, T-08, T-11, T-12
Context to read: `docs/adr/0010-ci-github-actions-path-filter.md`; `../spec.md` AC-12, AC-13; `../design.md` C-9, F-4; `../design-detail.md` §7; `../tests.md` TC-29…TC-32
Files to create/touch: `.github/workflows/ci.yml`, `infra/scripts/tests/test_ci_workflow.py` (parse the YAML; add `pyyaml` to the dev group), `Makefile` unchanged (CI calls existing targets)
Workflow: triggers `pull_request` and `push` to `main`; job `changes` (`dorny/paths-filter@v4`, filters per design-detail §7; shared Python set `packages/**`, `pyproject.toml`, `uv.lock`, `infra/scripts/**` maps to all five Python apps); `check-python` (if `python`; `astral-sh/setup-uv@v10`, `make setup-python`, `make check-python`, `make test-rules`), `check-web` (if `web`; `pnpm/action-setup@v6`, `make setup-web`, `make check-web`), `docs` (always: `make docs-check`), `build` (matrix of changed apps plus `migrate` when `infra/migrations/**` or `packages/db/**` changed; `make build APP=<name>`), `ci-ok` (`needs` all, `if: always()`, fails when any needed job failed or was cancelled). Actions pinned by major tag (`actions/checkout@v7`, `docker/setup-buildx-action@v4`).
Tests to turn green (write first): TC-29, TC-30 (unit proxies on the parsed filters); TC-31 and TC-32 are manual and run in `/spec-verify` after the repo is pushed.
Done when: unit tests pass; `ci.yml` passes a YAML/actionlint-style syntax check if `actionlint` is available (optional); the owner is told which pull requests to open for TC-31/TC-32.
Out of scope: branch protection, caching, SHA pinning, Dependabot, secret scanning (all in `backlog.md`), publishing images.
