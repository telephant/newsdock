2 Primary sequence: grouping one batch

sequenceDiagram
  participant K as gkg.clean
  participant S as Sink C-4
  participant P as Postgres C-5
  K->>S: copy #35;1 "T | SiteA" (url1)
  S->>S: story_key -> "t"
  S->>P: lookup (key "t", published ±48 h) -> none
  S->>P: INSERT articles (canonical, story_key "t")
  S->>P: INSERT article_sources (url1 -> canonical)
  K->>S: copy #35;2 "T" (url2, 1 h later)
  S->>S: story_key -> "t"
  S->>P: lookup -> canonical found
  S->>P: INSERT article_sources (url2 -> canonical)
  Note over S,P: redelivery of url1/url2: both inserts ON CONFLICT DO NOTHING
  S->>S: log "1 canonical, 1 grouped copy" (AC-12)
Check:
  • Crash after the canonical insert but before the source insert: what does redelivery do?
  • Both copies in the same batch: does the in-memory cache prevent a second canonical?
  • Same key but published 3 days apart — where exactly does the window guard bite?
