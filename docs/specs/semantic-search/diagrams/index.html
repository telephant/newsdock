2 Embed and backfill (F-16, F-17)

sequenceDiagram
  participant W as C-35 worker
  participant D as Postgres
  participant O as Ollama
  loop every poll
    W->>D: SELECT unembedded rows, newest first, LIMIT batch
    alt no rows
      W->>W: heartbeat, sleep idle
    else rows
      W->>O: POST /api/embed (titles with doc prefix)
      alt Ollama down
        O--xW: error
        W->>W: log, heartbeat, backoff
      else ok
        O-->>W: embeddings
        W->>D: UPDATE per row, guarded
        W->>W: heartbeat
      end
    end
  end
Check:
  • When nothing is left, is no request sent to Ollama (AC-3)?
  • When Ollama is down, do the rows stay untouched and the worker stay alive (AC-4)?
  • Do fresh rows get embedded before the old backlog?

3 Query (F-18, F-19)

sequenceDiagram
  participant G as Agent
  participant M as C-38 tool
  participant O as Ollama
  participant D as Postgres
  G->>M: semantic_search(query, mode, filters)
  M->>O: embed query (query prefix)
  alt Ollama down
    O--xM: error
    alt mode vector
      M-->>G: error embedding_unavailable
    else mode hybrid
      M->>D: keyword leg only
      M-->>G: results, degraded true
    end
  else ok
    O-->>M: vector
    M->>D: vector leg (HNSW, filters, model match)
    M->>D: keyword leg (full-text, same filters)
    M->>M: RRF fuse, cut to limit
    M-->>G: results with score and matched_by
  end
Check:
  • Do both legs use the same filters from one implementation?
  • Is the keyword search still available when Ollama is down (AC-10)?
  • Is the fusion a pure function over two id lists?

5 Embedding state of a row

stateDiagram-v2
  [*] --> Unembedded: sink inserts
  Unembedded --> Embedded: worker writes vector and model
  Embedded --> Stale: configured model changes
  Stale --> Embedded: worker re-embeds
  Unembedded --> Unembedded: Ollama down or bad vector
  Embedded --> [*]: retention deletes the row
  Unembedded --> [*]: retention deletes the row
  Stale --> [*]: retention deletes the row
Check:
  • Is a Stale row invisible to vector search until re-embedded (AC-11)?
  • Can every state end in retention, so nothing outlives 7 days (AC-13)?
